# tiny.common

## tiny.common 是什么

`tiny.common` 是一个面向**概念学习与最小化示例**的 TypeScript 工具库集合。仓库内包含一些“脚本/DSL”相关的 demo（例如 `src/scripts/jass/`），用于展示：

- 如何把字符串切分成 token（序列化/词法分析）
- 如何把 token 组织为可执行结构（解释执行/简单编译）
- 如何用极少代码表达“可组合调用/延迟执行”等概念

## 适用范围与非目标

本仓库刻意保持 “tiny”：

- 目标：**最小可用 + 易读 + 便于学习**，用于 demo 与概念验证。
- 非目标：完备脚本语言/生产级解释器/高安全沙箱/重量级特性。

如果你需要“完备脚本解释”，优先选择：

- 直接使用系统 `eval`（仅在可信输入/受控环境下）
- 或引入成熟第三方包（解析器/解释器/沙箱等），避免在本仓库内堆叠复杂度

## 快速上手（以 jass demo 为例）

- 入口：`src/scripts/jass/index.ts`（`JassScriptEngine`）
- 典型写法：`run([f1(2),f2(1)])`（列表延迟执行 + `run` 触发）

## 贡献建议（保持 tiny）

- 优先修正明显的正确性/性能问题（例如分词复杂度、调试输出、类型缺失）。
- 新特性以 demo 为导向：能讲清概念即可，避免追求语言完备性与全功能覆盖。
